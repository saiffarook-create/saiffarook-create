## Saif Zyada

Cybersecurity student at the University of East London, building ML-driven threat detection and secure web apps.

**Currently:** building Sanad, a compliance and risk platform for banks, and going deeper into detection engineering.

### Featured projects
- **[Phishing URL Detection](https://github.com/saiffarook-create/phishing-url-detection)**: LightGBM classifier with F1 0.946 and ROC-AUC 0.991 on a leakage-free split, SHAP explanations and a Streamlit demo.
- **[Identity Fraud Detection](https://github.com/saiffarook-create/identity-fraud-detection)**: account takeover detection comparing 3 ML models on imbalanced data, with CLI batch scoring.
- **[RBAC Manager](https://github.com/saiffarook-create/rbac-manager)**: access control dashboard with Supabase row-level security, a permission matrix and an audit trail.
- **Sanad**: GRC compliance platform MVP for banks, built with Next.js and Supabase.
